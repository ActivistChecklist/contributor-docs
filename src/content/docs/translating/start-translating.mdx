## Create an account on Crowdin
We use [Crowdin](https://crowdin.com/project/activistchecklist) to coordinate that review process. Anyone can contribute.

<Steps>
1. **Read the [code of conduct](/getting-started/code-of-conduct/)** so you know what we expect when you collaborate on translations.

1. **Create a free Crowdin account.** You can use an anonymous email address and username if you prefer (e.g. [Tuta](https://tuta.com)). If you want help deciding whether that matters for you, read [Protecting your privacy](/getting-started/protecting-your-privacy/).

    <LinkButton
      href="https://accounts.crowdin.com/register?continue=https%3A%2F%2Fcrowdin.com%2Fproject%2Factivistchecklist"
      icon="external"
    >
      Create a Crowdin account
    </LinkButton>

1. **Ask to join our Crowdin project.** We approve each request by hand, so you won't have access right away. New members start as translators: you can suggest edits and vote on translations.

    <LinkButton href="https://crowdin.com/project/activistchecklist" icon="external">
      Ask to join the Activist Checklist project on Crowdin
    </LinkButton>

1. **Tell us your username:** Fill out the [contact form](https://activistchecklist.org/contact/) here so we can approve your request. Once we know you, we can promote you to a "proofreader," which lets you approve translations.
    * Include your **Crowdin username** so we can find your request.
    * Include your **Signal username** so we can be in touch moving forward.
</Steps>

## Start translating

<Steps>
1. **Read the [translation style guide](/translating/translation-style/)** to understand how to translate the content in a way that matches our voice and tone.

1. **Find a file to work on.** Go to [our Crowdin project](https://crowdin.com/project/activistchecklist) > Select a language > Pick the first file in the [suggested review order](#suggested-review-order) that doesn't say 100% > To the right of the file, click on the three dots button **⋮** > **Proofread**.

1. **Edit or approve strings:** Find strings that do not have a green checkmark ✅ next to them. Approve items that look good. Edit items that need improvement.
</Steps>

## Suggested review order

We list the most visited pages first, so your work helps the most people right away. Start at the top and work down, skipping anything that's already at 100% in your language.

**Review each guide's checklist items too.** On Crowdin, each guide is split into several files. The guide file itself has the intro text and then a list of `<ChecklistItem>` elements that get replaced with the text present in the file. A guide isn't fully reviewed until all of its checklist items are reviewed.

To find a guide's checklist items, look for the `<ChecklistItem>` tags in the guide file you're reviewing. The `slug` is the name of the checklist item's file. For example, the Signal guide (`content/en/guides/signal.mdx`) has this line:

```mdx
<ChecklistItem slug="signal-disappearing" />
```

You'll find that checklist item in `content/en/checklist-items/signal-disappearing.mdx`.

Many checklist items show up in more than one guide, so each guide gets faster to complete as you go.
